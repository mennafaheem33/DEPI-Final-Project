# DEPI-Final-Project


Project Name: ATHR

Project Idea: 
The idea for ATHR came from noticing how difficult it can be for both locals and tourists to explore Egypt’s landmarks. Existing platforms were either outdated, complicated, or lacked personalization.  
 
We wanted to create a solution that:  
- Provides informative videos about each landmark  
- Shares essential tips for visitors to follow  
- Displays average prices to help plan visits  
- Highlights nearby services available around each site  
- Offers travelers a digital souvenir (STAMP) for every place they explore  
 
This way, exploring Egypt becomes simple, engaging, and memorable.
